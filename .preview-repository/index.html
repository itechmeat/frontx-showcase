FrontX site previews

This repository holds temporary previews of pull requests to constructorfabric/frontx-showcase, the FrontX site at frontx.cfabric.org.

Each preview sits at https://constructorfabric.github.io/frontx-showcase-previews/pr-<number>/; the pull request's comment links it. Previews are not indexed and are removed when their pull request closes or after a few days without a new build.
